# Letters

Requests sent on Where MPs Stand's behalf, kept as a record, one file per letter in a folder for its month. Each
starts with its To: and Subject: lines, and is sent from the charity's Gmail account with `deploy/mail.sh`, test copy
first ([docs/HOSTING.md](../docs/HOSTING.md#email-from-the-server) has the commands). A letter already sent is
skipped.

Replies arrive in the account's inbox. Record each in [ATTRIBUTION.md](../ATTRIBUTION.md) where it changes how a
source is used or credited, and in the family's letters and licences logs (`family/LETTERS.md` and
`family/LICENCES.md` in the charity's repository).
